# EgoVis — 第一人称具身数据标注与质量诊断流水线

> 从一段手机拍摄的 15 秒 ego 操作视频出发，跑通「原始数据 → 对象识别 → VLM 自动标注 → 质量诊断 → 数据缺口定位」的完整离线链路，服务于 VLA/WAM 训练数据生产。
> 面向具身数据算法岗位的作品集项目。

---

## 核心发现（TL;DR）

在 30 帧样本上量化出具身数据"脏"的三个层面，**发现并量化问题比跑高分模型更接近数据岗的本质**：

| 发现 | 数据 | 含义 |
|---|---|---|
| 通用检测器系统性失效 | 80% 有效检测是背景电器（键盘/电视/红绿灯），操作对象（杯/瓶）仅 **11%** | COCO 预训练模型迁移到 ego 场景会产生大量噪声标注 |
| VLM 标注有幻觉 | Qwen2.5-VL-7B 生成动作描述准确，但 **13%** Caption 提到画面中不存在的物体 | VLM 标注不能直接当 ground truth，需一致性校验 |
| VLM 有失败模式 | 前 4 帧模糊/无动作画面输出"无"；动作边界初版误报 12 个 | 需设计规则过滤无效标注，边界算法需处理短文本 |

**产出**：3 个可运行脚本 + 3 份结构化 JSONL 标注 + 1 份完整诊断报告（含面试讲稿）。

---

## 项目背景

具身智能（VLA / WAM）模型训练依赖高质量的"视觉-语言-动作"数据。真实采集的第一人称数据存在对象识别噪声、运动模糊、标注幻觉等问题。本项目验证：**如何用有限算力构建一条能暴露这些问题的离线数据流水线，并把问题转化为可执行的采集/清洗建议。**

## 方法

### 阶段一：4GB 显存质量诊断原型（本地 RTX 3050）

| 模块 | 方法 | 输出 |
|---|---|---|
| 数据准备 | 手机拍 15 秒 ego 视频，OpenCV 每 0.5s 抽帧 | 30 帧 |
| 对象识别 | YOLOv8n（COCO 预训练），置信度阈值 0.4 | `detections.jsonl`，80 个有效框 |
| 交互区域 | 最高置信框外扩 20% 作手-物体 ROI | 29 帧成功裁出 |
| 模糊诊断 | 拉普拉斯方差，阈值取第 25 百分位（自适应=25.3） | 8 帧标记模糊 |

### 阶段二：L40 46GB 自动标注升级

| 模块 | 方法 | 输出 |
|---|---|---|
| 动作 Caption | Qwen2.5-VL-7B-Instruct（bfloat16，16.6GB 显存），逐帧中文动作描述，附检测结果作物体提示 | `captions.jsonl`，30 条 |
| 动作边界 | 相邻 Caption 字符 bigram Jaccard 相似度 < 0.34 判边界，无需时序模型 | 7 个边界（修复假边界后） |
| 幻觉粗检 | Caption 提到物体词但检测结果无该类 → 疑似幻觉 | 4 帧（13%） |

---

## 关键工程决策（面试可讲）

1. **约束下的模型降级**：原计划 RT-DETR-l + MediaPipe 21 关键点，受显存/网络/API 变更限制，依次降级为 YOLOv8n + OpenCV 图像质量信号——优先保证闭环跑通。
2. **数据驱动的阈值**：模糊阈值不用硬编码（固定 100 会把 100% 帧判模糊），改用第 25 百分位，得到可信的 27%。
3. **算力匹配的模型选型**：46GB 上选 7B 而非更大 VLM，把时间留给"分析标注质量"而非"堆模型"。
4. **版本坑处理**：transformers 新版要求 torch≥2.6，固定 `transformers==4.51.3` 兼容 torch 2.5.1。
5. **主动发现并修复标注 bug**：bigram 相似度对单字 Caption（"无"）集合为空返回 0，导致前 4 帧连续假边界；修复为"相同文本→1.0"，边界数从 12 降到 7。体现对标注逻辑的细节敏感。

## 结果摘要

```
对象识别：30 帧 / 80 有效框 / 83% 帧含低置信度框
类别分布：keyboard 32 | tv 19 | traffic light 11 | person 7 | cup 6 | bottle 3 | mouse 2
          └─ 背景电器 64/80 (80%)     └─ 操作相关 9/80 (11%)

图像质量：模糊帧 8 (27%) / ROI 锐度 42.4 > 全图中位数 31.9

VLM 标注：30 条 Caption / 7 个动作边界 / 疑似幻觉 4 (13%)
样例 Caption：f_0004 "拿起杯子"[边界] → f_0005 "把水倒入杯中"[边界] → f_0006-7 "把水倒入杯中"
```

四类数据缺口与可执行建议见 [`reports/quality_report.md`](reports/quality_report.md)。

## 仓库结构

```
EgoVis/
├── README.md                    # 本文件
├── requirements.txt             # 依赖
├── src/
│   ├── extract_frames.py        # 视频抽帧（本地）
│   ├── detect.py                # 对象识别 + 低置信度统计（本地 4GB）
│   ├── hands.py                 # 交互 ROI + 自适应模糊诊断（本地，零额外依赖）
│   └── caption.py               # Qwen2.5-VL-7B Caption + 动作边界（L40 46GB）
├── data/
│   ├── raw/pour.mp4             # 原始 ego 视频（15 秒）
│   └── frames/                  # 30 帧抽帧结果
├── weights/
│   └── yolov8n.pt               # 本地权重（6MB，避免联网下载）
├── outputs/
│   ├── detections.jsonl         # 对象检测标注
│   ├── hands.jsonl              # ROI / 锐度标注
│   └── captions.jsonl           # VLM 动作标注（示例，见下方说明）
└── reports/
    ├── quality_report.md        # 完整诊断报告 v2（含面试讲稿）
    ├── detect_summary.md        # 对象识别摘要
    ├── hands_summary.md         # 质量诊断摘要
    └── roi_*.jpg                # 交互 ROI 可视化（30 张）
```

> `outputs/captions.jsonl` 为根据 `caption_summary.md` 中前 8 帧结果重建的示例标注，展示数据格式；完整 30 帧真实结果可在 L40 上运行 `src/caption.py` 复现（脚本见仓库）。

## 复现步骤

### 本地（4GB 显存，Windows/Linux 均可）

```bash
pip install -r requirements.txt
# 1. 把你自己的 ego 视频放到 data/raw/pour.mp4
python src/extract_frames.py     # 抽 30 帧
python src/detect.py             # 对象识别，OOM 自动降级
python src/hands.py              # ROI + 模糊诊断
```

### VLM 标注（需 ≥20GB 显存，Linux）

```bash
pip install "transformers==4.51.3" qwen-vl-utils accelerate modelscope
python src/caption.py            # 自动从 ModelScope 下载 Qwen2.5-VL-7B
```

## 与具身数据岗 JD 的对应

| JD 职责 | 本项目对应 |
|---|---|
| 数据质量、多元性分析 | 类别分布、锐度分布、低置信度/幻觉/空标注帧统计 |
| 与 VLA 算法团队协作定位数据缺口 | 四类缺口 + 可执行采集/清洗建议 |
| 预标注模型（对象识别 + 自动标注） | YOLOv8n 检测 + Qwen2.5-VL Caption |
| 自动标注满足 VLA/WAM 训练需要 | 结构化 JSONL（框/类别/动作/边界） |
| Ego 数据处理（自遮挡、运动模糊、快速缩放） | 交互 ROI + 自适应模糊诊断 + 空标注识别 |
| 推动采集、清洗和训练策略迭代 | 一致性校验规则 + 采集建议 |

## 局限与下一步

- 样本量小（30 帧），属概念验证；扩展到完整 episode 需处理时序一致性与去重。
- 手部姿态降级为图像质量信号，可在长时 GPU 上补 MediaPipe 21 关键点。
- 幻觉率 13% 为规则粗检，精确评估需人工抽样建立 gold set。

**升级路线**：修正边界重跑（已完成）→ 扩 2-3 场景 → GroundingDINO 开放词汇检测 → 人工复核建 gold set → 对齐 LeRobot 训练数据格式。

---

## 一句话总结

**这条流水线的价值在于用数据证明：具身数据的"脏"是系统性的——80% 背景垃圾标注、27% 模糊帧、13% VLM 幻觉。发现并量化这三层问题、给出清洗与采集建议，比跑一个高分模型更接近数据岗的本质工作。**
